# Careers analytics

GTM container GTM-NVBMRVP3, workspace 15, published version 15: Careers journey analytics (23 November 2026).

The `GA4 – Careers journey` event tag sends to the existing GA4 stream `G-4JGQVYM4ZG`, using the built-in Event variable. Its `Careers – Custom events` custom-event trigger uses an anchored allow-list regex. The Google Analytics initialization tag automatically generated by GTM is paused because the website already initializes this stream after analytics consent.

Events:
- careers_listing_view: careers listing mounted.
- careers_job_view: job advert mounted.
- careers_apply_click: apply CTA clicked.
- careers_application_start: application page mounted.
- careers_qualification_complete: eligible applicant advances to the application, once per mounted application.
- careers_cv_attached: a valid CV selected; no filename or file data sent.
- careers_application_submit: application endpoint confirms successful save.
- careers_application_error: submission attempt fails; no error message sent.
- careers_filter_change: nursery, posted-date, working-pattern or sort selection changed.

Events require the existing analytics consent to be granted and the canonical production host. Unknown event names are ignored. Preview and local hosts are excluded. There are no applicant names, contact details, qualifying answers, search strings, CV contents or filenames in the careers event payload. GA4's normal page URL identifies the public job page.

Existing Google Ads visit/registration conversion tags were preserved. Careers is not sent as a nursery enquiry conversion. No new Google Ads conversion action or GA4 key-event classification was created by this change.

Verification: TypeScript, production build, repository tests, dedicated consent/host/allow-list test, GTM UI confirmed version 15 live. A real application was not submitted for analytics testing, and GA4 report ingestion has not been verified.
